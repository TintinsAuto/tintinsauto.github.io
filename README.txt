# Tintin's Auto Detailing Website

A mobile-first website for Tintin's Auto Detailing, designed around Everett, Washington.

## Before publishing
Open `index.html` and change:
`const BUSINESS_EMAIL = "YOUR-BOOKING-EMAIL-HERE@example.com";`

Replace it with the email where you want booking requests sent.

## Optional next step
For true live appointment scheduling, connect a Calendly booking link and replace the booking form/button with your Calendly link or embed.

The logo is included as `logo.png`.
